---
title: "Get stats"
description: "Get aggregated statistics for all tracked events."
api: "GET https://api.oddpool.com/whales/user/stats"
---

## Parameters

<ParamField query="period" type="string" default="24h">
  Time period: `24h`, `7d`, or `all`.
</ParamField>

## Example

<CodeGroup>
```bash cURL
curl -H "X-API-Key: your_api_key" \
  "https://api.oddpool.com/whales/user/stats?period=7d"
```
```python Python
import requests

response = requests.get(
    "https://api.oddpool.com/whales/user/stats",
    headers={"X-API-Key": "your_api_key"},
    params={"period": "7d"}
)
data = response.json()
```
</CodeGroup>
