---

## Example

<CodeGroup>
```bash cURL
curl -H "X-API-Key: your_api_key" \
  https://api.oddpool.com/whales/user/markets
```
```python Python
import requests

response = requests.get(
    "https://api.oddpool.com/whales/user/markets",
    headers={"X-API-Key": "your_api_key"}
)
data = response.json()
```
</CodeGroup>
