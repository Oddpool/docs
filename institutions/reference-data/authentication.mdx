---
title: "Authentication"
description: "All Reference Data API requests authenticate with an API key in the X-API-Key header."
---

All requests require an API key in the `X-API-Key` header:

```text
X-API-Key: oddpool_<key>
```

```bash
curl -H "X-API-Key: oddpool_<key>" \
  "https://api.oddpool.com/reference/events?active=true&limit=100"
```

## Failure responses

| Status | Meaning |
|--------|---------|
| `401` | The `X-API-Key` header is missing or the key is unknown. |
| `403` | The key is recognized but doesn't include access to the reference data, or its trial window has elapsed. |

Both return a short string `detail`:

```json
{ "detail": "Invalid API key" }
```

```json
{ "detail": "Trial access for 'reference' expired at 2026-06-08T00:00:00+00:00." }
```

See [Errors](/institutions/reference-data/errors) for the full error envelope, including the structured `error_code` responses returned by `400` and `404`.
