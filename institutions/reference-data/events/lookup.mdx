---
title: "Resolve a venue identifier"
description: "Resolve a Kalshi or Polymarket identifier to the canonical event."
api: "GET https://api.oddpool.com/reference/events/lookup"
---

Accepts a Kalshi or Polymarket identifier and returns the canonical event with all attached venue listings, canonical outcomes, and linked entities.

Kalshi inputs may be either an event ticker or a market ticker — a market ticker resolves to its parent event. Polymarket atomic-binary markets carrying a `#N` side suffix are normalized during lookup.

## Parameters

Supply either `oddpool_id`, or `venue` + `id`.

<ParamField query="oddpool_id" type="string">
  Oddpool event identifier (`OPI-XXXXXXXX`). Mutually exclusive with `venue` + `id`.
</ParamField>
<ParamField query="venue" type="string">
  Venue tag: `kalshi`, `polymarket`, or `polymarket_us`. Required when looking up by `id`.
</ParamField>
<ParamField query="id" type="string">
  Venue-side identifier.

  - **Kalshi:** event ticker or market ticker.
  - **Polymarket:** conditionId (`0x…`), event slug, or numeric event id.
</ParamField>

## Example

<CodeGroup>
```bash cURL
curl -H "X-API-Key: your_api_key" \
  "https://api.oddpool.com/reference/events/lookup?venue=kalshi&id=KXBRASILEIROGAME-26MAY30GPACOR-GPA"
```
```python Python
import requests

response = requests.get(
    "https://api.oddpool.com/reference/events/lookup",
    headers={"X-API-Key": "your_api_key"},
    params={"venue": "kalshi", "id": "KXBRASILEIROGAME-26MAY30GPACOR-GPA"},
)
event = response.json()
```
</CodeGroup>

## Not found

Returns `404` with `error_code: EVENT_NOT_FOUND` when no canonical mapping exists for the identifier.

```json
{
  "detail": {
    "error_code": "EVENT_NOT_FOUND",
    "error": "no_canonical_match",
    "venue": "kalshi",
    "id": "KXNONEXIST-99"
  }
}
```
