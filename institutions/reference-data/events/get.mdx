---
title: "Get a matched event"
description: "Fetch a matched event by its Oddpool ID."
api: "GET https://api.oddpool.com/reference/events/{opi}"
---

Fetch one event by its Oddpool id. Same response as [Resolve a venue ticker](/institutions/reference-data/events/lookup#response) — the event, its outcomes, each outcome's entity, and the venue side you trade.

## Path parameters

<ParamField path="opi" type="string" required>
  The event id, e.g. `OPI-OO4GBEZJ`.
</ParamField>

## Request

<CodeGroup>
```bash cURL
curl -H "X-API-Key: your_api_key" \
  "https://api.oddpool.com/reference/events/OPI-OO4GBEZJ"
```
```python Python
import requests

r = requests.get(
    "https://api.oddpool.com/reference/events/OPI-OO4GBEZJ",
    headers={"X-API-Key": "your_api_key"},
)
event = r.json()
```
</CodeGroup>

## Errors

Returns `404` when no event has this id:

```json
{ "detail": { "error_code": "EVENT_NOT_FOUND", "error": "no_canonical_match", "oddpool_id": "OPI-NONEXIST" } }
```
