---
title: "Get an entity"
description: "Fetch an entity by its Oddpool ID."
api: "GET https://api.oddpool.com/reference/entities/{ope}"
---

Fetch one entity by its Oddpool id. Same response as [Resolve an entity](/institutions/reference-data/entities/lookup#response).

## Path parameters

<ParamField path="ope" type="string" required>
  The entity id, e.g. `OPE:TEAM:LOS-ANGELES-LAKERS`. Colons are URL-safe; `OPE%3ATEAM%3ALOS-ANGELES-LAKERS` works too.
</ParamField>

## Request

<CodeGroup>
```bash cURL
curl -H "X-API-Key: your_api_key" \
  "https://api.oddpool.com/reference/entities/OPE:TEAM:LOS-ANGELES-LAKERS"
```
```python Python
import requests

r = requests.get(
    "https://api.oddpool.com/reference/entities/OPE:TEAM:LOS-ANGELES-LAKERS",
    headers={"X-API-Key": "your_api_key"},
)
entity = r.json()
```
</CodeGroup>

## Errors

Returns `404` when no entity has this id:

```json
{ "detail": { "error_code": "ENTITY_NOT_FOUND", "oddpool_id": "OPE:PERSON:NOT-A-REAL-PERSON" } }
```
